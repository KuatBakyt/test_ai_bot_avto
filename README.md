# Review Studio
[![Checks](https://github.com/KuatBakyt/test_ai_bot_avto/actions/workflows/check.yml/badge.svg)](https://github.com/KuatBakyt/test_ai_bot_avto/actions/workflows/check.yml)

Учебное приложение для сбора подтверждённых отзывов и подготовки постов о выполненных работах: работа → диалог в Telegram → подтверждение отзыва → AI-черновик → публикация.

**Стек:** Python · Django REST Framework · PostgreSQL · Celery · Redis · OpenAI API · Telegram Bot API · Instagram API · Flutter.

## Возможности

- Работы и фотографии в личном кабинете владельца.
- Telegram-диалог с подтверждением точного текста отзыва.
- Генерация вступления к посту без изменения подтверждённого отзыва.
- Фоновые задачи подготовки и публикации, сохранение состояний и результатов.
- Деморежим без ключей OpenAI и Instagram: полный сценарий с имитацией публикации.

## Инженерные решения

- Раздельное согласие на AI-обработку и публикацию.
- Защита от повторных событий Telegram и повторной публикации при неизвестном результате.
- Приватные фото и временная ссылка для обработки Instagram.
- Отдельные демонстрационные данные, которые не превращаются в реальные публикации при смене режима.

[Исходный код и тесты сценария](tests/test_pipeline.py) · [Полная инструкция и ограничения интеграций](docs/reference.md)

## Локальная демонстрация

По умолчанию `DEMO_MODE=true`. Создайте `.env` из `.env.example`, задайте собственные секрет и пароль владельца, затем следуйте [инструкции запуска](docs/reference.md).

1. Создайте работу с фотографией.
2. Откройте тестовый диалог и подтвердите отзыв.
3. Разрешите подготовку поста и проверьте черновик.
4. Нажмите «Имитировать публикацию».

Backend: `http://localhost:8100`; Flutter: `http://localhost:8081`.

## Статус

Учебный MVP, публичный сервер пока не настроен. Деморежим ничего не публикует.
Реальные внешние вызовы требуют собственных ключей и настройки аккаунтов.
Instagram OAuth и обновление токенов в этой версии не автоматизированы.
